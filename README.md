#Regional Sales Summary

A small Python script that summerizes fictional regional sales data.
Built as part of lesson 0.6 of Coding Temple's AI Data Analytics Foundation Course.

## What it does

The script defines a dictionary of fictional sales values for five regions, then print the total and average across all regions.

## How to run
You need Python 3.10 or higher. From the terminal, in this folder:
Python regional_summary.py

(On Mac and Linux you may need Python 3 instead of Python.)

- 'regional_summary.py' - the main script
